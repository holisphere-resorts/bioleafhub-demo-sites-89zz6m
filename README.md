# BIOLEAFHUB — strony demo (7 koncepcji)

Data: 11.09.2026

## Co to jest
Siedem różnych pomysłów na stronę firmy BIOLEAFHUB s.r.o. i marki EIRRA. Wszystkie działają,
wszystkie można klikać. Służą do rozmowy: „która droga nam się podoba”.

- **Demo 1 — Butik / jubiler** — wygląd marki luksusowej.
- **Demo 2 — Apteka / laboratorium** — czysto, biało, badania i liczby na wierzchu.
- **Demo 3 — Natura / rzemiosło** — pole, ręczna robota, ciepłe zdjęcia.
- **Premium 1 — Material Atlas** — strona jak katalog surowców i badań.
- **Premium 2 — Objects of Quiet** — EIRRA jako ciche, drogie przedmioty.
- **Premium 3 — Hemp Estate 360** — panoramy 360°, obracasz obraz myszką.
- **Walk the field** — prawdziwy spacer 3D po polu konopnym w przeglądarce.
